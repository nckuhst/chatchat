# 編輯聊天題目

| 檔案 | 畫面上的階段名稱 |
| --- | --- |
| `warmup.ts` | 輕鬆開個頭 |
| `star1.ts` | 多認識一點 |
| `star2.ts` | 分享心情 |
| `star3.ts` | 聊聊心裡話 |

修改對應檔案裡的 `text` 就能更換題目。例如：

```ts
{ id: 'w-01', tier: 'warmup', text: '你最近最喜歡的一個小時刻是什麼？' },
```

- 修改文字時保留原有 `id` 與 `tier`，讓進行中的存檔仍可繼續使用。
- 新增題目可以複製一整行，指定未使用過的 `id`（各階段前綴為 `w-`、`s1-`、`s2-`、`s3-`），並保留行尾逗號。
- 題目數量可自由增減，每個階段至少留一題。題目會自動匯入，階段內會隨機排序。
- 刪除題目後，包含該題的舊存檔會失效，需要開始新的一回。新增題目會在新的一回出現。
- 執行 `npm test` 檢查題目 ID、文字與階段，並用 `npm run build` 檢查格式與建置。
